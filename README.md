Это расширение снимает ограничения заложенные сайтом VacNet, заменяет плеер и предзагрузку страницу, добавляет панель вердиктов с горячими клавишами, распознаёт повторные клипы, переводит интерфейс на русский и ведёт полную историю просмотренных вердиктов, а также добавляет некоторые твики для удобства использования.

## Возможности

### 🎬 Снятие ограничений

Воспроизведение начинается с начала записи. Окно оцениваемого клипа отмечено на полосе перемотки, подозрительный момент выделен красным маркером. Таймер Valve, который ограничивает воспроизведение 12-секундным окном и возвращает назад при попытке перемотки, перехватывается через `setInterval`/`setTimeout` и отключается, вердикты отправляются моментально без подтверждений, клипы предзагружаются без перезагрузки страницы.

### 🎮 Современный видеоплеер

Стандартный Video.js портала заменяется на [Plyr](https://plyr.io/) — лёгкий медиаплеер с чистым интерфейсом. Скорости от 0.25× до 4×, покадровая перемотка (`←`/`→`), переключение 2× зума (`Z`), запоминание уровня громкости. Перед подозрительным моментом появляется оверлей с обратным отсчётом, а в момент срабатывания явный указатель на что именно среагировал VacNet.

### ⚖️ Панель вердиктов

Четыре категории — Aim Assist, Wall Hack, Auto Bhop, Bot — с вариантами **Да** / **Не уверен** / **Нет**, цветовая кодировка и управление с клавиатуры. Отправка вердикта **не перезагружает страницу**: следующий клип подгружается фоновым запросом, сохраняя позицию воспроизведения и полноэкранный режим. При ошибке загрузки — автоматический откат к стандартной навигации портала.

### 🔁 Обнаружение дубликатов

Клипы идентифицируются по уникальному VOD ID видеозаписи + дате создания клипа + временному диапазону. Когда портал повторно выдаёт тот же момент с новым ID задачи, расширение распознаёт точный дубликат, показывает предыдущие вердикты и, если включена настройка, автоматически подставляет их для быстрого подтверждения.

### 📊 История и метрики

Каждый размеченный клип сохраняется в `browser.storage.local`. Панель мониторинга работает в двух режимах:

- **История** — записи сгруппированы по матчам, с диапазонами клипов, ID задач, статусом дедупликации и разбивкой вердиктов по каждому клипу.
- **Метрики** — живые данные текущего клипа: ID задачи, ID видео, WebM URL, диапазон, время события, дата матча, статус идентификации, информация о Plyr.

Импорт и экспорт истории в JSON.

### 🌍 Локализация

Расширение включает английскую и русскую локализации. Текст интерфейса портала — вопросы, кнопки, метки, инструкции — переводится в реальном времени через DOM mutation observer, без перезагрузки страницы.

### 🔒 Приватность и безопасность

Ник проверяющего скрыт по умолчанию. Все настройки (растягивание видео, закреплённые контролы, громкость, автоприменение дубликатов) хранятся локально. Расширение проверяет каждый переход между страницами — формы действия сверяются с допустимым доменом, HTML-атрибуты санитизируются, `javascript:` URL удаляются, тяжеловесные и сломанные алгоритмы valve глушатся.

## Что исправляет

Портал работает, но имеет реальные проблемы:

| Проблема | Что делает расширение |
| --- | --- |
| Воспроизведение ограничено ~12 сек | Перехватывает таймеры Valve и снимает ограничение, позволяя смотреть всю запись |
| Нет скоростей выше 1× | Plyr даёт 0.25×–4× и покадровую перемотку |
| Диалог деталей клипа не открывается | Портал привязывает модалку к несуществующему элементу — расширение читает метаданные напрямую |
| Отправка вердикта перезагружает страницу | Форма отправляется фоново, следующий клип подгружается без потери состояния |
| Layout не использует экран | Видео фиксированной высоты, панель вердиктов 500px — расширение использует адаптивный flex layout |
| Индикатор «Отправка…» не пропадает | Расширение управляет состоянием отправки напрямую |

## Горячие клавиши

| Клавиша | Действие |
| --- | --- |
| `Пробел` | Воспроизведение / Пауза |
| `R` | Перезапуск с начала клипа |
| `Z` | Переключить 2× зум |
| `← →` | Покадровая перемотка |
| `Enter` | Отправить вердикт |
| `Esc` | Закрыть панель |

> Все горячие клавиши привязаны к физическим клавишам (`event.code`), поэтому корректно работают на любых раскладках клавиатуры.

## Установка

### Chrome, Edge, Brave, Opera

1. Скачайте zip из [Releases](https://github.com/MartinDawgor/VacNet-Toolkit-Extension/releases).
2. Откройте `chrome://extensions`, включите **Режим разработчика**.
3. Перетащите zip на страницу.

### Firefox

1. Скачайте Firefox-версию zip из [Releases](https://github.com/MartinDawgor/VacNet-Toolkit-Extension/releases).
2. Откройте `about:debugging#/runtime/this-firefox`.
3. Нажмите **Загрузить временное дополнение** и выберите zip.

> **Примечание:** расширение использует content script в мире `MAIN` страницы для перехвата таймеров воспроизведения Valve. Требуется **Firefox 128+**; для Chrome дополнительных требований нет.

## Приватность

- **`storage`** — хранит историю разметки и настройки в `browser.storage.local`.
- **`https://www.counter-strike.net/*`** — единственное разрешение на хост. Расширение не работает на других сайтах.

Никакой аналитики, телеметрии и удалённого кода. Единственный сетевой запрос — отправка вердикта на `counter-strike.net` при подтверждении, тот же запрос, который сделал бы сам портал. Ничего не передаётся разработчику или третьим сторонам.

История не покидает браузер, если вы не экспортируете её в JSON вручную.

## Отказ от ответственности

Это расширение — слой удобства поверх портала разметки. Оно **не размечает клипы за вас**, не отправляет вердикты автоматически и не автоматизирует процесс ревью.

Каждый ответ выбираете вы. Отправка требует явного нажатия. Вердикт из ранее просмотренного клипа подставляется для подтверждения или изменения — никогда не отправляется сам. Нет массовой разметки, автоматического перехода и скриптовых ответов.

Патрульным рекомендуется не стримить, не записывать и не распространять клипы, поэтому в расширении нет экспорта кадров, скачивания клипов или функций обмена. Ник патрульного скрыт по умолчанию.
