## **Настраиваемые пресеты вердиктов**
# **Changelog**
* В панель оценивания добавлена строка быстрых пресетов (`LEGIT`, `AIM`, `WH`, `RAGE`) и кнопка сброса `↺`, позволяющие выставить вердикты по всем 4 категориям в один клик.
* Реализовано всплывающее меню настройки пресетов (**⚙**): можно свободно изменять названия кнопок и гибко настраивать значения для каждой категории (Aim, WH, BHop, Bot) через удобные селекторы.
* Пользовательские настройки пресетов автоматически сохраняются локально (`localStorage`) и не сбрасываются при смене клипа или перезагрузке страницы. Добавлена кнопка сброса настроек по умолчанию.
* Добавлен протокол пакетного выставления вердиктов `set-verdicts` в обработчик рантайма.
